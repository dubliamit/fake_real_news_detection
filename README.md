# Fake News Detection using Machine Learning and NLP

## Project Overview

With the rapid growth of digital media and online information consumption, misinformation and fake news have become significant challenges. This project leverages Natural Language Processing (NLP) and Machine Learning techniques to automatically classify news articles as **Fake** or **Real**.

The solution uses **TF-IDF Vectorization** for feature extraction and compares the performance of multiple traditional machine learning algorithms, including:

* Logistic Regression
* Support Vector Machine (Linear SVM)
* Multinomial Naive Bayes

The objective is to build an accurate and scalable text classification system capable of detecting misleading news content.

---

## Business Problem

The widespread dissemination of fake news can influence public opinion, create social unrest, and spread misinformation. Manual verification is time-consuming and cannot keep pace with the volume of online content.

This project demonstrates how machine learning can assist media organizations, fact-checking agencies, and social media platforms in identifying potentially deceptive content automatically.

## Dataset Information

**Dataset Size:** 45,757 News Articles

**Features:**

* text : News article content
* label : Target variable

  * 1 = Real News
  * 0 = Fake News

### Data Characteristics

* Highly balanced classes

## Results

| Model                   | Accuracy |
| ----------------------- | -------- |
| Logistic Regression     | 97.71%   |
| Linear SVM              | 98.58%   |
| Multinomial Naive Bayes | 93.39%   |

**Best Performing Model:** Linear SVM

The Linear SVM model achieved the highest classification performance due to its effectiveness in handling high-dimensional sparse text data generated by TF-IDF vectorization.
